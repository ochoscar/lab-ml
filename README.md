# Machine Learning Lab

A personal playground for learning, experimenting, and building Machine Learning solutions.

This repository contains notes, experiments, prototypes, datasets, and implementations of machine learning algorithms and techniques. The primary goal is to deepen my understanding of ML concepts through hands-on practice and real-world projects.

## Objectives

- Learn Machine Learning fundamentals.
- Explore supervised and unsupervised learning algorithms.
- Build reproducible experiments.
- Practice data preprocessing and feature engineering.
- Evaluate and compare different models.
- Learn model deployment and production best practices.
- Document lessons learned and key insights.

## Development

Install dependencies:

```bash
poetry install
```

Run the project:

```bash
poetry run python src/main.py
```

Run tests:

```bash
poetry run pytest
```

Run Ruff:

```bash
poetry run ruff check .
poetry run ruff format .
```
